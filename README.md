# 🎓 Student Grade Checker

A sleek, premium, and fully responsive web application that calculates student grades and outcomes instantly. Built from scratch with a focus on custom styling, visual data states, and adaptive mobile screen configurations.

🔗 **Live Demo URL : https://student-grader-gules.vercel.app/**

---

## ✨ Features

- **Automated Grading Engine:** Instantly evaluates scores out of 100 against an internal scoring rubric.
- **Dynamic UI Presentation:** Automatically swaps colors, themes (green for pass, red for fail), borders, and FontAwesome status icons based on student outcomes.
- **Robust Input Validation:** Guarded defensively against empty strings, non-numeric values, or out-of-bounds metrics (less than 0 or greater than 100).
- **Responsive Layout Architecture:** Smoothly transitions into a stacked, "click-to-swap" view on screens smaller than 992px (covering mobile and portrait tablets like iPad Mini), while maintaining a side-by-side card layout on desktop viewports.
- **One-Click Reset Workspace:** Complete workspace wipe feature via a "Clear All" button to allow rapid back-to-back testing.

---

## 🛠️ Built With

- **HTML5:** Semantic architecture structure.
- **CSS3 (Flexbox & Media Queries):** For customized layouts, smooth dynamic component scaling, soft shadows, and tablet/mobile view configurations.
- **Vanilla JavaScript (ES6+):** Event tracking handlers, form validation gates, evaluation conditions, and immediate DOM text/style manipulation updates.
- **FontAwesome:** Scalable vector icons for data state illustration.
- **Google Fonts:** Premium typography styling (`Lora` and `Nunito`).
